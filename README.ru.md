# Трекер задач студента

[English](README.md) · **Русский**

Домашнее задание по Web Development 2: Express, EJS, сессии, роли и промежуточные обработчики.

## Запуск

```bash
npm install
npm start
```

Откройте <http://localhost:3000>. Учебные логины для входа перечислены в [английской версии](README.md).

Адреса для проверки: `/admin` (только администратор), `/tasks/999` (404), `/crash-test` (500), любой неизвестный
адрес (страница 404).

## Устройство

```
index.js     только соединяет части
middleware/  по файлу на каждый обработчик
routes/      вход, задачи, администрирование
lib/store.js чтение и запись файлов данных
views/       страницы EJS
```

## Порядок обработчиков

Журнал запросов, статические файлы, разбор форм, сессия, общие переменные страниц, маршруты, страница 404 и в конце
обработчик ошибок. Почему порядок именно такой, подробно объяснено в [английской версии](README.md).

Пароли хранятся открытым текстом только потому, что так требует задание.
